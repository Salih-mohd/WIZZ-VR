VR Voice-Driven Interaction Prototype

This is a small VR prototype focused on interaction, discovery, and voice-based spell casting.

Overview

The player is trapped inside a dungeon-like environment and can interact with various objects.
Some interactions trigger effects or scares, while others unlock abilities such as spell casting or flight.

Features

XR-based object interaction with audio, animation, and VFX feedback

Discovery-based gameplay where abilities are unlocked through exploration

Offline voice-controlled spell casting using Vosk

Wand-based spell execution and broomstick flying mechanic

Controls

Use VR controllers to interact with objects

Speak unlocked spell keywords out loud to cast spells

Notes

This project was built as a one-week prototype to experiment with VR interaction systems and voice input, not as a full game.
